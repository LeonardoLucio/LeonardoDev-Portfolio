# Portfólio · Leonardo Lúcio

Landing page pessoal construída com React, Vite e styled-components.

## Requisitos

- Node.js 20.19 ou superior
- npm

## Desenvolvimento

```bash
npm install
npm run dev
```

O Vite informa no terminal o endereço local para abrir no navegador.

## Build de produção

```bash
npm run build
npm run preview
```

Os arquivos finais são gerados em `dist/`.
